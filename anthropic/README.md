# Anthropic Plugin

Expert knowledge about Anthropic APIs and protocols.

## Skills Included

- **model-context-protocol** - Comprehensive knowledge of the Model Context Protocol (MCP) for connecting AI applications to external systems

## Installation

This plugin is part of the API-Docs marketplace.

```bash
/plugin marketplace add Yan-Yu-Lin/API-Docs-Plugin
/plugin install anthropic@api-docs
```
